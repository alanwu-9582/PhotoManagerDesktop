# 介面設計規範

一套桌面工具軟體的介面規範：顏色、字體、尺寸、元件與版面規則。照著做，就能做出外觀與操作手感一致的不同工具。
規範只談「長什麼樣子、怎麼互動」，不涉及任何特定功能。

數值單位一律是**邏輯像素**（高 DPI 螢幕由系統縮放）。顏色以 `#RRGGBB` 或 `rgba()` 表示。

---

## 0. 七條總則

1. **同一列等高**：同一列裡所有可操作的元件（按鈕、下拉、輸入框、分段、開關、步進器、滑桿列）高度一律 **30**。
2. **圓角上限**：任何元件的圓角半徑都 **小於自己最短邊的 1/3**。程式裡用一個函式統一夾住，不要手算。
3. **寬度要對齊**：設定欄裡的分段控制、步進器、下拉選單撐滿整列；兩個並排時各佔半列。分段控制裡每一段等寬。
4. **寬度不跳動**：可捲動的設定欄永遠保留捲軸的位置；切換分頁、內容變長變短，欄寬都不變。
5. **畫面上少放字**：不寫操作說明。說明放在滑鼠停留的提示裡；空狀態只留一句話。
6. **值的型別決定元件**：連續的值用滑桿，有級距的值用步進器或分段，見〈5. 數值輸入〉的對照表。
7. **計算慢的效果不要卡住操作**：先給草稿、放開才定稿，計算一律在背景執行。

## 1. 色彩

### 1.1 色票（Token）

介面只透過下列 token 取色，不在元件裡寫死色碼。淺色、深色兩套跟著作業系統切換，切換時不需要重建元件。

|---|---|---|---|
| `window` | `#f5f5f7` | `#1c1c1e` | 視窗底色、對話框底色 |
| `content` | `#ffffff` | `#232325` | 卡片、群組框、浮起的面 |
| `sidebar` | `#ebebef` | `#28282b` | 側邊欄 |
| `elevated` | `#ffffff` | `#2c2c2e` | 選單、下拉清單、提示框 |
| `control` | `#ffffff` | `#3a3a3c` | 輸入框、下拉選單的底 |
| `control_hover` | `#f2f2f5` | `#444447` | 下拉選單滑過 |
| `fill` | `rgba(120,120,128,0.12)` | `rgba(120,120,128,0.24)` | 次要按鈕、分段控制的軌道、滑過的底 |

| `secondary` | `#6e6e73` | `#a1a1a6` | 次要文字、欄位標題 |
| `tertiary` | `#a1a1a6` | `#6e6e73` | 停用文字、佔位圖示 |
| `separator` | `rgba(0,0,0,0.10)` | `rgba(255,255,255,0.10)` | 半透明分隔線 |
| `separator_hex` | `#e0e0e5` | `#3a3a3d` | 不透明分隔線、外框 |
| `accent` | `#5856d6` | `#7d7aff` | 強調色：主要按鈕、選取、焦點 |

| `slider_thumb_hover` | `#4b49c8` | `#d4d2fb` | 滑桿把手滑過、拖曳中 |

系統色（狀態、標籤、圖表分類）：

| | red | orange | yellow | green | teal | blue | purple | gray |
|---|---|---|---|---|---|---|---|---|
| 淺色 | `#ff3b30` | `#ff9500` | `#ffcc00` | `#34c759` | `#30b0c7` | `#007aff` | `#af52de` | `#8e8e93` |
| 深色 | `#ff453a` | `#ff9f0a` | `#ffd60a` | `#30d158` | `#40c8e0` | `#0a84ff` | `#bf5af2` | `#98989d` |

### 1.2 用色規則

- **強調色只有一種用途：「這是主要的、這是被選中的」**。用在主要按鈕、選取的分段或卡片外框、焦點框、滑桿已填滿的部分。不拿來裝飾。
- 破壞性動作用 `red`：只有「確定刪除 / 覆蓋」那顆按鈕是實心紅色；畫面上常駐的危險動作用紅字無底按鈕。
- 成功、警告、錯誤的提示用 `green` / `orange` / `red` 的小圓點或淡底（約 14% 不透明度），不要整片塗滿。
- **預覽畫布永遠是深色**（`canvas`）：被檢視的內容顏色才不會被淺色背景襯偏。
- 疊在畫布上的浮動元件一律用深色半透明底 `rgba(28,28,30,0.84)`、白色文字，與主題無關。

## 2. 字體

### 2.1 字族

| 平台 | 介面字 | 等寬字 |
|---|---|---|
| Windows | Segoe UI → Microsoft JhengHei UI → Microsoft JhengHei | Cascadia Mono → Consolas |
| macOS | 系統字（SF）→ PingFang TC → Helvetica Neue | SF Mono → Menlo |
| Linux | Inter → Noto Sans CJK TC → Noto Sans | JetBrains Mono → DejaVu Sans Mono |

- 用**靜態字型**並開啟**完整 hinting**（字形貼齊像素格）；可變字型在小字級沒有 hinting，會糊。
- 拉丁字母與中文分別指定字族，讓兩種文字都用為螢幕調校過的字型。
- 字級一律用像素指定，不用點數。

### 2.2 字級階層

| 名稱 | 大小 | 字重 | 用途 |
|---|---|---|---|
| large | 26 | 700 | 頁面大標題 |
| title2 | 18 | 600 | 對話框標題、詳細面板標題 |
| title3 | 16 | 600 | 空狀態標題、警示框標題 |
| headline | 14 | 600 | 群組框標題、卡片標題 |
| body | 14 | 400 | 一般文字、按鈕 |
| callout | 13 | 400 / 600 | 滑桿名稱、分段文字、步進器數值 |
| caption | 12 | 400 / 600 | 狀態列、提示框、標籤、小註記 |

- **區段標題**（設定欄裡分組用）：caption、600、`secondary` 色、上方多留 10；若是英文就轉大寫。
- 數值（滑桿值、色碼、檔名這類）用等寬字，數字變動時不會左右跳。
- 文字色只用 `label` / `secondary` / `tertiary` 三級，不另造灰色。

| 項目 | 數值 |

| 圖示按鈕 | 30 × 30（工具列中可用 22 × 22 的無底版） |
| 捲軸寬 | 11（把手 7，滑過變 11） |

### 3.2 間距

| 位置 | 數值 |
|---|---|
| 頁面邊距 | 左右 24、下 16 |
| 頁面內區塊間距 | 12 |
| 工具列元件間距 | 8 |

### 3.3 圓角

| 元件 | 半徑 |
|---|---|
| 卡片、預覽畫布 | 12 |

## 4. 元件

### 4.1 按鈕

| 種類 | 外觀 | 用在 |
|---|---|---|
| 主要 | `accent` 實心、`on_accent` 粗體字 | 一個區域裡最主要的那一個動作，**一個區域只有一顆** |
| 次要（預設） | `fill` 底、`label` 字 | 其他動作 |
| 無框 | 透明底、`accent` 字，滑過出現 `fill` | 連結式的輕量動作 |
| 危險無框 | 透明底、`red` 字 | 常駐的危險動作入口 |
| 破壞性 | `red` 實心、白色粗體字 | 只出現在確認對話框裡 |
| 圖示 | 透明底，滑過 `fill`，切換開啟時 `accent_soft` | 工具列小動作、刪除列 |

- 高度 30、圓角 7。圖示在文字左側，間距約 4。
- 停用：文字 `tertiary`、底 `fill`（主要按鈕停用時也變回灰底）。
- 按鈕文字是動詞，2–6 個字；需要解釋的寫在提示裡，不寫在按鈕旁。
- 會開對話框或需要再選擇的動作，文字結尾加「…」。

### 4.2 分段控制（Segmented）

```
┌───────────────────────────────────────────┐
│ ▐ 選項一 ▌  選項二  │  選項三  │  選項四   │   軌道：fill、圓角 7
└───────────────────────────────────────────┘
   ↑ 選中段：淺色 #ffffff／深色 #636366，圓角 5.5，下方 0.6 的淡陰影，文字變粗
```

- 高 30；軌道內縮 2，選中段浮在軌道上。
- **每一段等寬**：以最長的文字（用粗體量）＋左右內距（一般 26、緊湊 20）為準。
- 未選中的段之間畫 1 像素的細分隔線（上下各縮 5）；選中段的兩側不畫。
- 滑過未選中的段，出現一塊 `fill`。
- 放在設定欄、分頁列：**撐滿整列**（並排時半列）。最小寬度可以縮到「最長文字 + 12」× 段數，不撐破欄位。
- 放在工具列、跟其他按鈕同一行：用緊湊版，維持剛好的寬度。
- 2–5 個互斥選項用它；更多選項改用下拉選單。
- 可用鍵盤左右鍵切換。

### 4.3 步進器（Stepper）

有級距、有順序的值：

```
┌────┬──────────────────┬────┐
│ ‹  │       ×1.5       │  › │    外框：fill、圓角 7
└────┴──────────────────┴────┘
  30     中間 ≥ 60（2 × 30）    30
```

- 兩側箭頭鈕各 30 × 30，箭頭圖示 13；到頭的那一側箭頭變 `tertiary`、不可按。
- **中間數值區的寬度至少是單側箭頭鈕的 2 倍**，也要放得下最長的選項；底色同分段控制的選中段，圓角 5.5，文字 callout 600。
- 點中間的數值，跳出所有選項的選單直接挑（目前值打勾）。
- 鍵盤左右 / 上下鍵一格一格換。
- 設定欄裡撐滿欄寬；工具列裡維持最小寬度。

### 4.4 滑桿

兩種。

**A. 欄位式滑桿**：設定項目不多、每個都需要標題時用。

```
標題                       數值
████████████▮──────────────────     軌道 8 高、圓角 2；把手 10 × 22、圓角 3
```

- 上面一行：左邊標題（`secondary`），右邊目前值（等寬字）；下面一行是滑桿，整體高度 30。
- 已經滑過的部分用 `accent` 填滿。

**B. 參數列滑桿**：一長串參數（調整面板那種）用，一個參數一列。

```
名稱(86)   ─────────●──────────   +25(46)      整列高 30
```

- 左：名稱，固定寬 86（放不下就省略號）；中：軌道 4 高、圓角 2；右：數值，固定寬 46，靠右。
- 把手是直徑 12 的圓，滑過或拖曳時變 14；顏色 `slider_thumb`。
- **雙向數值**（例如 −100…+100）：中點上方畫一個小刻度；填色從中點畫到目前值，而不是從最左邊。
- **漸層軌道**：數值本身就是一個色彩方向（冷暖、色相、色調）時，軌道直接畫成那個漸層，不另外填色。
- 數值偏離預設時，名稱與數值變成 `label` 色、名稱變粗；在預設值時兩者都是 `secondary`。看一眼就知道哪些參數被動過。

**兩種滑桿共同的行為**：

- **點軌道的任何位置，直接跳到那個值**（不是往那邊跳一格），而且可以不放開接著拖。
- 按在把手上不會先跳一下，從按下的位置開始拖。
- **雙擊回到預設值**。
- 鍵盤左右 / 上下一格；按住 Shift 一次十格。
- 值的變化分兩個事件：拖曳中的「變化」與放開後的「確定」。計算慢的效果只接「確定」。

### 4.5 開關（Toggle）

```
┌────────────────┐        ┌────────────────┐
│    文字開關    │  關    │▐▐▐ 文字開關 ▐▐▐│  開（內塊填 accent、字變白）
└────────────────┘        └────────────────┘
```

- 高 30。外框 `content` 底 + 1 像素 `separator_hex` 框（滑過時框變 `tertiary`），圓角 6。
- 開啟時，內縮 3 的內塊填 `accent`，圓角 4；文字 callout 600、白色。
- 關閉時文字 `secondary`，滑過變 `label`。
- 可以只放圖示：30 × 30 的方形，圖示 17，文字放進提示。
- 鍵盤焦點：外框改成 `accent` 色。

### 4.6 輸入框與下拉選單

- 高 30、圓角 7、`control` 底、1 像素 `separator_hex` 框。
- 焦點：框變成 2 像素 `accent`（內距同時減 1，文字不會位移）。
- 輸入錯誤：框變成 2 像素 `red`；不另外跳訊息。
- 唯讀 / 停用：底改 `fill`、框透明、文字 `secondary`。
- 佔位文字用 `tertiary`，寫「要輸入什麼」，不寫說明句。
- 下拉箭頭是 10 × 10 的向下 chevron（`secondary` 色），右側留 22。
- 展開的清單：`elevated` 底、1 像素框、圓角 8、內距 4；選取列 `accent` 底白字。

### 4.7 色彩按鈕

- 預設 46 × 30（色塊樣本可縮成 30 × 30），圓角 7，內部填滿該顏色，外圍 1 像素框。
- 點擊開系統調色盤；同一列可並排幾個常用色樣本，點了直接套用。

### 4.8 標籤與徽章

- **標籤（chip）**：一個詞的可選小按鈕，高 30、內距 5 × 12、圓角 6；選中時 `accent` 底白字 600，未選中 `fill` 底。用流式排列（自動換行），間距 6–8。
- **徽章**：按鈕右側的小計數，高 18、caption 600、圓角 5，距按鈕右緣 8；需要注意時用 `accent` 底白字，只是資訊時改 `fill_strong` 底、`secondary` 字。

### 4.8.1 二維控制板

兩個互相關聯的連續值（例如「深 / 亮」×「淡 / 濃」）用一塊方形控制板，不要拆成兩條滑桿：

- 188 × 188，圓角 14，`content` 底 + 兩層極淡漸層提示方向；中間 11 × 11 的點陣，中軸的點稍大。
- 四邊各一個字標示方向（caption 600、`secondary`）。
- 圓點：白色直徑 18、中心 8 的 `accent` 實心點；拖曳移動，**雙擊回中心**，沒有另外的「歸零」按鈕。
- 旁邊用一小段文字顯示兩個軸的數值。

### 4.9 卡片

- `content` 底、1 像素 `separator_hex` 框、圓角 12；內距 10–16。
- 有圖的卡片：圖在上，裁成卡片的寬高比（cover），跟卡片共用上方的圓角；文字區在下，標題 headline，下面一行 caption `secondary`。
- 選中：2 像素 `accent` 外框（圓角 = 卡片圓角 + 外擴距離）。滑過：框變 `tertiary`。
- 沒有圖時畫佔位：`fill` 底、置中的 26 號圖示（`tertiary`）＋一行 caption。
- 卡片格線用流式排列，間距 14；卡片寬度固定，欄數隨視窗變。

### 4.10 縮圖格子（選擇用）

一排選項各自帶小預覽時用，例如預設樣式：

- 96 × 92：上方預覽 90 × 64、圓角 7；下方名稱 caption，選中時變粗、`label` 色。
- 選中：2.5 像素 `accent` 框圍住預覽。
- 以 3 欄格子排列，間距 6；分組時每組上面一個區段標題。
- 預覽在背景產生，算好一格補一格，不讓使用者等。

### 4.11 群組框

```
┌ 標題（headline）────────────────────────┐
│ 內容（內距 16 / 14、內部間距 10）        │
└──────────────────────────────────────────┘
```

- `content` 底、1 像素 `separator_hex` 框、圓角 10。
- 設定頁用一個個群組框垂直排列，間距 12；群組框裡只有標題，沒有說明段落。

### 4.12 對話框（Sheet）與警示框

**一般對話框**：
- 標題 title2，內容區可伸縮，底部按鈕列靠右：「取消」在左、主要動作在右。
- 寬 520–820，依內容；固定高度的要讓內容區可捲動。
- 主要動作在必要欄位填好之前是停用狀態，不跳錯誤訊息。

**警示框（確認）**：
- 寬 420–560；左側 30 號圖示（一般 `accent` 的 info，警告 `orange`、危險 `red` 的 alert），右側標題（title3 粗）＋說明（`secondary`）。
- 危險確認：確認鍵是實心紅色，**預設焦點停在「取消」**；按 Enter 不會直接執行。
- 一般確認：預設焦點在確認鍵。

### 4.13 選單

`elevated` 底、1 像素框、圓角 9、內距 5；項目內距 5 × 22 × 5 × 10、圓角 4；滑過 `accent` 底白字；分隔線 1 像素、左右各縮 8。

### 4.14 提示訊息（Toast）

- 視窗底部置中、距底 96；高 40、寬隨文字（文字寬 + 58）。
- 底 `rgba(30,30,32,0.92)`、圓角 10、白字 body 500；左側一個狀態小圓點（info `accent`、success `green`、warning `orange`、danger `red`）。
- 淡入淡出 180 毫秒，停留 2.6 秒。
- 只用來回報「已完成」或「做不了」，不用來教學。內容 4–16 個字。

### 4.15 提示框（Tooltip）

- 自繪：`elevated` 底、1 像素 `separator_hex` 框、圓角 6、內距 8 × 4、文字 caption 500、最寬 320 自動換行。
- **操作說明一律放這裡**，例如快捷鍵、拖曳方式、按鈕的作用與限制。
- 結尾附快捷鍵：「動作說明（Ctrl+S）」。

### 4.16 空狀態

置中排列：44 號圖示（`tertiary`）→ 間距 6 → 標題 title3 → 一句說明（`secondary`）→ 視需要一顆主要按鈕。說明只有一句，告訴使用者下一步。

### 4.17 進度

- 細進度條：高 5–6、圓角 1，`fill_strong` 底 + `accent`。
- 長時間工作：在動作按鈕旁顯示「進行中：步驟名稱… 42%」（caption）＋寬 160 的進度條；同時讓觸發的按鈕停用。
- 背景計算中的畫布：右上角一個小標籤「計算中…」（深色半透明底、白字 caption 600、圓角 6）。

### 4.18 捲軸

- 11 寬、透明軌道；把手平常 7 寬（`fill_strong`），滑過變 11 寬（`tertiary`）；最短 36。
- 可捲動的設定欄**永遠保留捲軸位置**；不需要捲動時把手隱藏，只留空白，切換內容時寬度不跳動。

## 5. 數值輸入：該用哪一個元件

| 值的性質 | 元件 | 例子 |
|---|---|---|
| 連續、單向（0…100） | 參數列滑桿／欄位式滑桿 | 強度、品質、羽化 |
| 連續、雙向（−100…+100） | 參數列滑桿（中點填色） | 偏移、增減 |
| 連續、本身是顏色方向 | 漸層軌道滑桿 | 冷暖、色調、色相角度 |
| 連續、精細角度 / 小數 | 欄位式滑桿（步距 0.1） | 微調角度 |
| 有級距、有順序、超過 5 級 | **步進器** | 縮放級數、每排幾個、每頁筆數 |
| 2–5 個互斥選項 | 分段控制 | 模式、方向、樣式 |
| 6 個以上的選項、或沒有順序 | 下拉選單 | 尺寸規格、形狀種類 |
| 開 / 關 | 開關 | 顯示與否、自動與否 |
| 兩個相關的連續值 | 二維控制板 | 色調 × 色彩 |
| 在一個分佈上選一段範圍 | 直方圖 + 兩個把手 | 範圍、區間 |
| 顏色 | 色彩按鈕 + 常用色樣本 | 底色、文字色 |
| 短文字 | 輸入框 | 標題、名稱 |
| 長文字 | 多行文字框 | 內文、範本 |

**不要**用滑桿表示只有少數幾級的值：使用者拖不準，也看不出有幾級。

## 6. 版面

### 6.1 主視窗

```
┌─────────┬──────────────────────────────────────────────────┐
│  品牌   │ 頁面大標題                        來源 / 全域動作 │
│         │ 工具列（分段、步進器、下拉、按鈕…）       計數   │
│ 分組標題│ ┌──────────────────────────────────────────────┐ │
│ ▣ 頁面  │ │                                              │ │
│ ▣ 頁面  │ │                 頁面內容                     │ │
│         │ │                                              │ │
│ 分組標題│ └──────────────────────────────────────────────┘ │
│ ▣ 頁面  ├──────────────────────────────────────────────────┤
│ ⊟    ◐  │ 狀態列：來源 · 數量 · 狀態 · 進度                │
└─────────┴──────────────────────────────────────────────────┘
```

- **側邊欄**：展開寬 212、收合寬 60（只剩圖示）。`sidebar` 底、右側 1 像素分隔線。
  - 項目高 32、左右縮 8、圓角 7；圖示 17（左距 10）+ 文字 body 500（圖示後 38 起排）。
  - 選中：`accent_soft` 底、圖示變 `accent`、文字加粗到 600（文字仍是 `label` 色）；未選中的圖示是 `secondary`，滑過出現 `fill` 底。
  - 收合時圖示置中，名稱改放在提示裡。
  - 分組標題 caption 600 `secondary`，左縮 18，組與組之間多留 12。
  - 最下方放收合按鈕與外觀切換。
- **狀態列**：高 30，上方 1 像素分隔線；文字 caption，用「 · 」分隔；右側可放 160 × 5 的進度條。
- 頁面切換用 Ctrl + 數字快捷鍵，依側邊欄順序。

### 6.2 頁面

- 大標題（large）在左上；同一列右側放影響整個頁面的動作。
- 下面一列是工具列：全部高 30、間距 8；相關的控制項用 1 像素直線（左右各 6 的間距）分組；伸縮空白之後放計數或次要資訊。
- 頁面層級的分頁列：撐滿整列的分段控制，放在工具列的位置。

### 6.3 「畫布 + 設定欄」版型

編輯類工具的標準版型：

```
┌──────────────────────────────────┐  ┌─────────────────────────┐
│                                  │  │ 分頁列（固定，不捲動）   │
│          預覽畫布                │  ├─────────────────────────┤
│        （深色、圓角 12）          │  │ 區段標題                │
│                                  │  │ 欄位 / 欄位（各半列）    │
│ ▸ 資訊面板            ◉ ⟲ 100%  │  │ 參數列滑桿…             │▐ ← 捲軸位置永遠保留
└──────────────────────────────────┘  │ …（可捲動）              │
[選擇來源] [其他來源]                  │                         │
狀態文字                  [暫存] [儲存…]└─────────────────────────┘
```

- 左右用分割線分開，比例約 3 : 2（例如 760 : 420），把手 16、兩側都不可收合。
- **設定欄寬度**：至少放得下「所有分頁裡最寬的內容 + 捲軸」，下限 340；用同一組設定欄的幾個工具共用最大的那個寬度。切換分頁或工具時欄寬不變。
- 設定欄上方的分頁列不捲動；右緣跟下方內容對齊（扣掉捲軸的寬度）。
- 動作列在畫布下方靠右：次要動作在左、主要動作在最右邊。
- 畫布下方左側放「選擇來源」類按鈕，再下一行是一行 caption 狀態文字。

### 6.4 設定欄的排法

- 由上到下：區段標題 → 欄位。區段之間 12。
- **欄位** = 上方標題（`secondary`）+ 下方控制項，間距 5。
- 兩個欄位並排時各佔一半（間距 14），左右對齊上下文。
- 一列滑桿參數直接堆疊，不加欄位標題（名稱在滑桿列裡）。
- 用「整列 / 半列」兩種寬度就好，不做三分之一。若一列三個，就改成兩列。
- 不放說明段落；需要的話放在該元件的提示裡。

## 7. 預覽畫布

### 7.1 外觀

- 底色 `canvas`、圓角 12；內容縮進 18 置中（符合畫布）。
- 內容超出畫布時沿圓角裁切。
- 空的時候：置中兩行字「選擇內容」（title3 600、白色 60%）＋「點這裡，或拖進來」（callout、白色 40%），點擊即開檔。
- 拖檔案進來：畫布出現 2 像素 `accent` 虛線框；放開即載入。

### 7.2 浮動元件（疊在畫布上）

全部用深色半透明底 `rgba(28,28,30,0.84)`、白字、1 像素 `rgba(255,255,255,0.12)` 外框、圓角 10，距畫布邊 12。

- **右下：工具列（HUD）**：30 × 30 的圖示鈕（滑過 14% 白、選中 24% 白、按下 30% 白）＋縮放百分比文字。視需要提供：
  - 「隱藏框線」：眼睛圖示，切換後變成劃掉的眼睛。
  - 「符合視窗」。
  - 縮放比例（以符合視窗為 100%）。
- **左下：資訊面板**：收起時是一顆 26 高的膠囊（chevron + 標題）；點了展開成面板，裡面上方是小分頁、下方是圖表或兩欄的鍵值列表。展開狀態與所選分頁要記住。
- **上方置中：狀態標籤**：例如「原始」，64 × 24、圓角 6。

### 7.3 互動

- **滾輪**：以游標為中心縮放（倍率 e^(滾動量 × 0.0016)），範圍 100%–800%。
- **拖曳**：放大後左鍵拖曳移動；正在用左鍵編輯畫布上的物件時，改用中鍵拖曳。
- **雙擊**：在「符合視窗」與 250% 之間切換；正在編輯畫布物件時停用雙擊縮放。
- **按住空白鍵**：暫時顯示比較對象（例如原始狀態），放開回來；輸入文字時不攔截空白鍵。
- 放大超過預覽解析度時，停止操作 0.25 秒後，用原始解析度重算看得到的那一塊並蓋上去。
- 不需要縮放的畫布（以點選為主的工具）就不提供縮放，工具列只留需要的按鈕。

### 7.4 畫布上的編輯物件

- 外框畫兩次：先畫 3 像素黑色 47% 不透明，再畫 1.4 像素白色。在任何內容上都看得清楚。
- 選取中：實線；未選取：虛線、白色 60%。
- 把手：8 × 8 白色方塊（1 像素黑框）；旋轉把手是物件上方 26 的白色圓點，用一條細線連回物件。
- 中心點：直徑 8，選取中是 `yellow`、未選取是白色。
- 都可以用「隱藏框線」一鍵藏起來檢視成果。

## 8. 圖表

### 8.1 一般圖表

- 卡片內放圖表：卡片標題 headline + 灰色小註記（單位、軸名）。
- 長條：`accent` 單色，圓角 3；滑過的那一條保持原色，其他降到 45% 不透明度。
- 環圈圖：最多 6 片，其餘併入「其他」；中間顯示總數（title3 700）；圖例在右，名稱 + 百分比。
- 熱力圖：格子間留 2 像素、圓角 3；顏色從 `fill` 到 `accent`，用**平方根**換算，少數極大值才不會把其他格子壓成空白；右下附「少 ▬▬▬ 多」圖例。
- 散佈圖：泡泡大小代表數量（面積隨平方根），半透明 55%，滑過 95%。
- 滑過任何資料點都顯示提示框「名稱：數值」。
- 一排卡片等高（拉伸到同列最高的那張）；最後一排空出來的格子，由最後一張卡片橫向補滿。

### 8.2 深色面板上的小圖表

疊在畫布上的資訊面板裡的圖表：

- 圖表區底色 `rgba(0,0,0,0.35)`、圓角 5。
- 多條資料疊加用「相加」混合（R / G / B 各 41% 不透明），重疊處自然變灰白。
- 參考線用白色 12–27% 不透明；文字白色 47–92% 不透明，分層。
- 警示指示（例如超出範圍）：小三角形，有問題時白色、沒問題時 20% 白。

## 9. 互動與回饋

### 9.1 計算與等待

- 任何超過約 50 毫秒的計算都放到背景執行緒；介面不凍結。
- **兩段式預覽**：先用小尺寸算草稿（約 0.1 秒）立刻顯示，再算正式預覽替換。拖曳中只算草稿，放開才算正式的。
- 很慢的效果（超過 0.5 秒）：拖曳時完全不算，**放開滑桿才算**；點選、切換類的單一動作立即算。
- 新的請求進來就取消舊的計算，只顯示最新參數的結果。
- 匯出、暫存等長工作顯示進度與步驟名稱，期間停用觸發的按鈕。
- 關閉程式時背景工作要能安靜結束，不報錯。

### 9.2 狀態保留

- 工具之間共用「目前處理的對象」；在一個工具裡暫存的結果，切到另一個工具就接著用。上方出現一條小註記「正在編輯『某工具』的結果」，附「改回原始」的無框按鈕。
- 介面偏好（分頁、展開狀態、欄數、側邊欄收合、視窗位置）都記住。
- 換一個新對象時，跟對象綁在一起的調整值歸零，避免重複套用。

### 9.3 鍵盤

| 鍵 | 作用 |
|---|---|
| Ctrl + 數字 | 切換頁面 |
| Ctrl+O / Ctrl+S | 開啟 / 儲存 |
| Ctrl+Shift+S | 暫存（不寫檔） |
| Space（按住） | 暫時顯示比較對象 |
| Delete | 刪除選取的畫布物件 |
| ← → | 分段控制、步進器、滑桿換值；Shift 加大步距 |
| Enter / Esc | 對話框確認 / 取消（危險確認的預設是取消） |

### 9.4 確認與破壞性動作

- 會動到使用者檔案的動作一律先確認，標題用問句（「刪除『名稱』？」），說明寫清楚會發生什麼、不會發生什麼。
- 刪除只放在有意義的地方（使用者自己建立的東西）；內建的東西不給刪除鈕，而不是給了再拒絕。

## 10. 文字

- **畫面上不放操作說明**。拖曳方式、快捷鍵、限制條件都放進提示框。
- 群組框、設定欄只有標題，沒有說明段落。
- 狀態類文字只顯示結果：「已儲存 2000×1500 · 檔名」「已複製」「快速估計」。細節放提示。
- 空狀態一句話，告訴下一步：「從上方『開啟資料夾』開始。」
- 數字用千分位，單位緊跟數字並空一格（「1,280 筆」「42 MB」）；比例用「×」。
- 標點用全形；英文與數字前後與中文之間空一格。
- 名稱一致：同一個動作在按鈕、提示、選單、確認對話框裡用同一個詞。

## 11. 圖示

- 24 × 24 網格的線條圖示，筆畫 2、圓頭圓角；檔案裡用黑色，繪製時換成需要的顏色。
- 介面中顯示為 13–17：按鈕內 15–16、側邊欄 17、步進器箭頭 13、空狀態 44。
- 圖示顏色跟著文字：一般 `label`、停用 `tertiary`、強調 `accent`、畫布上白色。
- 同一個意思只用一個圖示（例如「重設」「符合視窗」用同一個回轉箭頭）。

## 12. 自我檢查清單

做完一個畫面，逐項確認：

- [ ] 同一列的控制項高度都是 30。
- [ ] 沒有任何圓角大於自己短邊的 1/3。
- [ ] 設定欄裡的分段控制、步進器、下拉選單撐滿整列或半列，上下左右緣對齊。
- [ ] 分段控制每一段等寬。
- [ ] 步進器中間數值區 ≥ 單側箭頭的 2 倍。
- [ ] 切換分頁、工具、內容長短時，設定欄寬度不變。
- [ ] 沒有欄位被裁切（最窄的視窗也檢查）。
- [ ] 有級距的值沒有用滑桿。
- [ ] 滑桿點軌道直接跳到該值；雙擊回預設。
- [ ] 慢的計算不會在拖曳中執行；有草稿、有進度。
- [ ] 畫面上沒有操作說明段落；說明都在提示框。
- [ ] 主要按鈕每個區域只有一顆，而且在最右邊。
- [ ] 危險確認的預設焦點是「取消」。
- [ ] 淺色、深色主題都檢查過；畫布在兩種主題都是深色。
